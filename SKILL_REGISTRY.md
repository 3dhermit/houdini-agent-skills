## rendering

Configure a Karma (or mantra) Render Output ROP: driver, resolution, frame range, output path, AOV requests. Config only - it does not silently render.

**Trigger prompts that should select this skill**
- "set up a karma render"
- "configure aovs"
- "set render resolution"
- "point a render rop at my geo"

**Actions** (payload schema lives in `skills/rendering/meta.json`)
- `configure` - required: none; optional: aovs, container, engine, frames, output_path, path, resolution, samples
- `inspect` - required: path; optional: none
- `list_engines` - required: none; optional: none

**Examples**
```bash
hython -m houdini_skills.cli rendering configure --json '{"container":"asm_render","path":"/obj/asm_sop/bevel1","resolution":[960,540]}'
```

## v1.0.0 known limitations

- Verified only on 22.0.368; the 19.5-21.x floor is declared, not tested.
- `simulation-tools` does not author DOP graph contents and never steps a sim.
- `rendering` never renders; Karma AOV authoring is out of v1.
- `usd-pipeline` proves one file landed; layer stacks / MaterialX are out of scope.
- Karma requires H20+, so the 19.5 floor gets an explicit `engine_unavailable` error.
